## 4. Controls

| Action | Key |
|--------|-----|
| Shoot the ball | ⬇️ Down Arrow |
| Control flippers | ⬅️ ➡️ Left/Right Arrows |
| Enable/Disable colliders | `F1` |
| Enable/Disable mouse joint | `F2` |
| Change gravity | `F3` |
| Change FPS (60 ↔ 30) | `F4` |
| Change bumper bounciness | `F5` |
